## Folder Alias

Unity 2022.3.22f1の標準Rename操作から、`Assets` 配下のフォルダについて表示名だけを変えるか、実フォルダ名を変えるか選択できるVRChat向けEditorパッケージです。表示名が設定されたフォルダは黄色で表示され、Projectウィンドウ内では表示名を優先して自然順に並びます。
