# Folder Alias

UnityのProjectウィンドウにある `Assets` 配下のフォルダへ、標準Rename操作から実名とは別の表示名を設定するVRChat向けEditor専用パッケージです。Unity `2022.3.22f1` のみに対応します。

## 使い方

1. Projectウィンドウで既存のフォルダを選択します。
2. Unity標準の `Rename` または `F2` で名前を入力し、Enterで確定します。
3. 表示されるダイアログで処理を選択します。

- `表示名のみ変更`: 実際のフォルダ名を変更せず、Projectウィンドウの表示名だけを変更します。
- `フォルダ名を変更`: Unity標準の物理Renameを続行し、そのフォルダの表示名設定を解除します。
- `キャンセル`: どちらも変更しません。

表示名を実際のフォルダ名と同じ名前へ戻して `表示名のみ変更` を選ぶと、表示名設定が解除されます。
表示名が設定されているフォルダをRenameして入力欄を空白のまま確定した場合も、選択ダイアログを出さずに表示名設定が解除され、実際のフォルダ名へ戻ります。

設定はプロジェクトルートの `ProjectSettings/FolderAliases.asset` に保存されます。チームで同じ表示名を共有する場合は、このファイルをバージョン管理に含めてください。

## 変更しないもの

- ディスク上のフォルダ名とパス
- フォルダのGUIDと `.meta`
- `AssetDatabase` が返すパス
- unitypackageのインポート先と更新動作
- スクリプトや参照が利用するアセットパス

表示名の設定はフォルダGUIDに紐づくため、同じGUIDを含むunitypackageを再インポートしても維持されます。表示名が設定されているフォルダ名は黄色で表示されます。
Projectウィンドウ内のフォルダは、表示名が設定されている場合は表示名、設定されていない場合は実際のフォルダ名を優先して自然順に並びます。Unity標準のフォルダ優先表示は維持されます。

## 表示だけが変わる範囲

変更対象はProjectウィンドウ内のフォルダ項目ラベルです。検索、Projectウィンドウ上部のパンくず、OSのファイル表示、APIが返す名前やパスでは、実際のフォルダ名が使われます。

本パッケージはUnity `2022.3.22f1` の内部ProjectBrowser実装を検証して利用します。別バージョンでは互換動作を試みず、初期化エラーにします。
